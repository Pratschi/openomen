## 💬 Support & Feedback
To receive support, report bugs, feature requests, or report bugs, you can: 
* Open an issue on the [GitHub Repository](https://github.com/openomen/openomen/issues)
* Join the [Discord Server](https://discord.gg/UHQ5cztbUj) for more and better updates!

When you report an issue, please try to always show the output of `openomen info` (*OpenOMEN v3.0.0+*) or at least your **Laptop Model and Linux Distribution**.

## ⁉️ FAQ
**¿Why is there no source code?**
<br>The source code hasn't been released since there isn't a fully-stable release and first the source code has to be cleaned up for the public release, but it will still be released sometime soon.

**¿How do you test compatible laptop models?**
<br>We use feedback from users running different laptops and operating systems to check for any issues or incompatibility.

**¿What's happening right now with OpenOMEN?**
<br>OpenOMEN is constantly receiving upgrades and we're planning to create an **Interface** and some **Keyboard RGB customization**.

**¿Is my laptop compatible with OpenOMEN?**
<br>To ensure compatibility with OpenOMEN, please check the **Compatibility Section** of the wiki and check your **Laptop Model** and your **Linux Distribution**
