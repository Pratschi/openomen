## 📦 OpenOMEN Installation

### 1. Download

Download the latest version of the Binary Executable from the [releases](https://github.com/openomen/openomen/releases) page.


### 2. Make the script executable:

Navigate to the directory where the script is located and run:
```bash
chmod +x openomen
```
(Optional) You can move OpenOMEN to your path to execute it everywhere:
```bash
sudo mv openomen /usr/local/bin/
```
### 3. Run the executable

You can now run the script via terminal:

```bash
openomen
```

## 🛠️ Updating OpenOMEN
### Version v0.2.1+
Since version *v0.2.1+* you can update OpenOMEN with:
```bash
openomen update
```
### Older Versions / Manual Updating
To update it manually or with older versions, delete your older **OpenOMEN Installation** with:
```bash
sudo rm /usr/local/bin/openomen
```
And then follow the **Installation Steps** in the section above.
